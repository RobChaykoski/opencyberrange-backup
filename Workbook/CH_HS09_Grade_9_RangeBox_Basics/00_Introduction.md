# High School Cybersecurity — Grade 9 RangeBox Basics

## Welcome

This chapter is for students who are new to the training desktop. You do not
need to know how to code, and you do not need to install anything.

RangeBox is a Linux desktop that runs in your browser. It gives you a terminal,
a browser, and the tools used in later exercises. Learning to move around
RangeBox now makes every later lab easier.

If RangeBox is not available on your deployment, you can still complete these
activities with the lab browser or any terminal your teacher provides.

## What You Need

- A browser
- The exercise panel open in OpenCyberRange
- A RangeBox desktop, or the lab browser as a fallback

## How to Launch RangeBox

1. Open an exercise in the High School track.
2. Choose **Launch RangeBox**.
3. Pick the **Kali** desktop.
4. Wait for the desktop to finish loading.
5. Open the terminal from the taskbar or application menu.

The first launch can take a minute while the desktop starts. That is normal.

## A Few Terminal Basics

| Command | What it does |
|---|---|
| `pwd` | Prints the folder you are currently in |
| `ls` | Lists the files in the current folder |
| `whoami` | Prints your account name |
| `cd FOLDER` | Moves into a folder |
| `cat FILE` | Prints the contents of a text file |
| `curl URL` | Requests a web page or file |

You do not have to memorise these. Use this table as a reference.

## A Safe Place to Practise

- Every target in this chapter is fictional.
- You cannot break the practice server.
- Using hints is part of learning.
- You can pause, ask for help, or stop at any time.
- If a command produces an error, read the error before trying again. Errors are
  information, not failure.
